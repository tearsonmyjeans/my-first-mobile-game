# Основное

## Решено

- **Для кого:** для себя, друга и нескольких знакомых. В сторы не выкладываем, персонажи из других вселенных (Мистер Жопосранчик, V1, V2) остаются как есть.
- **Формат:** веб-игра в одном HTML-файле, удобная на телефоне. Движок для полноценной версии пока не выбран (предлагался Godot).
- **Графика:** милый пиксель-арт, мягкая палитра, цветной контур. Сотрудники 23×32 px, станки около 32 px, иконки карточек 16×16. Всё рисуется кодом: спрайты сотрудников заданы строками символов (сжатие RLE, `.` прозрачный), каждый символ — цвет из `PAL`. Буквы в `PAL` уже заняты, новые цвета добавляются знаками препинания.
- **Сеттинг:** маленький завод, который растёт. Каждый новый цех выпускает новый продукт, и продукты всё абсурднее: доски → кирпичи → гвозди → стекло → мебель → носки → пицца → кетчуп → резиновые уточки → тостеры-роботы → …
- **Главная механика:** карточки (станки, сотрудники, экипировка, улучшения) комбинируются между собой, а станки и сотрудники усиливают соседей.
- **Прогрессия:** бесконечная, числа идут через K, M, B, T и дальше.

## Как устроена игра

- **Экран сверху вниз:** деньги и уровень, вкладки цехов, сцена цеха с раздевалкой, панель выбранного станка или сотрудника, кнопки «Магазин», «Колода», «Меню».
- **Цеха:** у каждого своя сетка мест. Соседи — места, которые касаются стороной. Подробности в [цехах](workshops.md).
- **Сотрудники:** каждый существует в одном экземпляре и работает только на одном станке на весь завод. Без сотрудника станок стоит. Подробности в [сотрудниках](employees.md).
- **Раздевалка:** общая для всех цехов, страницы по 16 шкафчиков в два ряда по 8, переключаются кнопками 1, 2… в шапке раздевалки. Впереди всегда есть страница со свободными шкафчиками; когда приходит новый сотрудник, открывается страница с его шкафчиком. В шкафчике лежит экипировка сотрудника. Соседи по шкафчику в одном ряду дружат: +5% силы друг другу. Шкафчики можно менять местами.
- **Доход станка:** скорость станка × скорость сотрудника × цена × сила сотрудника, плюс бонусы соседей, карточек, удачи (шанс двойной штуки), скиллов и комбо.

## Баланс

| Что | Значение |
|---|---|
| Опыт до следующего уровня | 15 × 1,6^(уровень − 1); опыт равен заработанным монетам |
| Цена магазина | 40 × 2,2^(число покупок) |
| Посылки на полу | раз в 45–90 с, живут 20 с |
| Выбор карточки | 1 из 3; вес редкости 10 / 5 / 2 / 1 |
| Первая карточка | всегда Верстак, Крепкий кофе, Тренажёр |
| Открытие цехов | кирпичи 300, гвозди 3000, стекло 30 000 |
| Офлайн-доход | 50% дохода без скиллов, максимум за 4 часа |

## Сохранение

Прогресс хранится в браузере игрока (localStorage, ключ `pixel-factory-save-v1`, версия сохранения 8). Старые сохранения обновляются сами. Если меняется структура, нужно добавить шаг миграции в `migrate()`.

## Идеи на будущее

- Прокачка скиллов: второй уровень дольше действует или быстрее перезаряжается.
- Заказы клиентов с наградами («200 гвоздей за 3 минуты»).
- Медленнее рост уровней и прокачка станков за монеты.
- Перезапуск завода ради постоянного бонуса, новый забег с другим набором карточек.
- Сырьё и цепочки между цехами: поздние цеха используют продукцию ранних.
- Усталость сотрудников, поломки станков.
- Слияние 3 одинаковых карт в 1 улучшенную, ежедневная награда.
- Карточки, меняющие соседство: «Вентиляция» (весь столбец), «Длинные руки» (диагонали), «Одиночка» (сильнее без соседей).
- Общая таблица лидеров для друзей.
- Цеха крупнее: сетки 4×4 и 5×5 с необычной раскладкой, как кольцо в цеху стекла.
