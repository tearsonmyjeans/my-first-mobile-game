# Первая локация: цех досок

Стартовая локация. Продукт — доски.

## Места под станки (билд 1)

- На первой локации **3 места в ряд**. Игрок сам решает, куда ставить станок.
- Карты станка работают только с соседями по ряду:
  - станок посередине касается двух соседей;
  - станок с краю касается одного.
- Конвейер связан со всем рядом.
- Дальше по прогрессии места расширяются (идея: 3×3 на следующих этапах).

## Станки цеха (макет v1)

| Станок | Что делает |
|---|---|
| Пилорама | Распиливает брёвна на доски. Главный станок цеха |
| Верстак | Строгает доски, и они дорожают |
| Сушилка | Работает медленнее, зато сухие доски дороже |
| Конвейер | Перевозит доски. Связан со всем своим рядом |
| Шлифовальный станок | Полирует доски до блеска |

## Связки соседних станков (черновик)

| Пара | Бонус |
|---|---|
| Пилорама + Верстак | +10% к цене |
| Пилорама + Сушилка | +8% скорости |
| Пилорама + Конвейер | +12% скорости пилорамы |
| Верстак + Шлифовальный | +15% к цене |
| Конвейер + Шлифовальный | +5% скорости |
| Сушилка + Конвейер | +7% скорости |
| Сушилка рядом с любым станком | +20% к цене |
| Пилорама рядом с любым станком | +15% скорости |
| Конвейер | +30% скорости всему ряду |
| Любая другая пара | +3% к цене |

## Экран

Сверху вниз:
1. деньги, доски, уровень;
2. переключатель цехов;
3. сетка 3×3;
4. строка выбранного станка;
5. раздевалка со шкафчиками;
6. выбор карточки.

Макет: `design/factory-mockup-v1.html`.

## Билд 1

Играбельная веб-версия лежит в `game/index.html`.

- **Старт:**
  - пилорама в центре, за ней Ворона;
  - Мистер Жопосранчик ждёт в раздевалке.
- **Источники карт:**
  - новый уровень;
  - посылки на полу (появляются раз в 45–90 с);
  - магазин за монеты.
- **Комбо:**
  - комплекты по тегам: каждая пара карт одного тега;
  - «Ночная смена» (Кофе + Конвейер + Бродяга: доход ×1,5);
  - «Две пилорамы».
- **Сохранение:** прогресс хранится в браузере. Пока игра закрыта, завод зарабатывает 50% дохода, максимум за 4 часа.
