# Пиксельный завод

Рогалик-менеджер в пиксель-арте для себя и друзей. Завод растёт от цеха досок до абсурдных производств. Игрок расставляет станки и сотрудников, собирает карточки, и они усиливают друг друга по соседству.

Игра целиком в одном файле `game/index.html`: открывается в браузере, в том числе на телефоне. Опубликована как артефакт: https://claude.ai/artifact/L48eiUyCvvwgykiJagULB6

## Документы

- [Основное](docs/main.md): концепция, правила, баланс, планы.
- [Цеха](docs/workshops.md): места, станки, связки.
- [Сотрудники](docs/employees.md): характеристики, перки, скиллы, внешность.
- [Карточки](docs/cards.md): все карточки и комбо.
