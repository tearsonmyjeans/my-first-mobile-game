# Карточки

**Откуда берутся:** каждый 3-й уровень, выполненная квота, витрина в перерыве между сменами (3 карты с ценой по редкости, купить можно одну, потом витрину надо обновить за монеты). Каждый раз выбор 1 из 3, выбор можно перебросить за монеты. Карточки закрытого цеха не выпадают, сотрудник выпадает, только пока его нет, станок — пока их меньше максимума (см. [цеха](workshops.md)) и есть свободное место.

**Редкость:** обычная (серая), редкая (синяя), эпическая (фиолетовая), легендарная (золотая).

**На карте при выборе и на витрине** зелёным видно «+X/с»: сколько дохода карта добавит в лучшем месте прямо сейчас (новый сотрудник примеряется к каждому станку). У карт с минусом минус написан отдельной красной строкой.

**Карты мастерства** не выпадают как обычные: на каждом 9-м уровне (9, 18, 27…) вместо обычной карты выбор 1 из 3 карт мастерства, каждая берётся один раз за забег.

Эффекты карт — множители: две одинаковые карты ×1,3 дают ×1,69. **Комплекты по тегам:** каждая пара карт одного тега даёт бонус: «Сотрудники» +5% силы всем, «Экипировка» +5% скорости всем, «Станки» +5% к цене, «Улучшения» +3% ко всему доходу.

## Комбо

| Комбо | Условие | Эффект |
|---|---|---|
| Ночная смена | Крепкий кофе + Конвейер + Бродяга | весь доход ×1,5 |
| Растопка | пилорама работает в цеху 1 | печи в цеху 2 +25% скорости |
| Закалка | печь работает в цеху 2 | проволока в цеху 3 +20% к цене |
| Дуэт горничных | V1 и V2 на соседних станках | доход их цеха ×2 |
| Зелёная сила | Пришелец и Хаба на соседних станках | сила обоих ×1,5 |
| Семейный подряд | Хаба, Кастомка, Батя | двое на соседних станках +20% силы; все трое в одном цеху: доход цеха ×2 |
| Рамы на гвоздях | барабан работает в цеху 3 | витражи в цеху 4 +20% к цене |
