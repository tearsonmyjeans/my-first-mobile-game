# Мобильная игра: пиксельный завод

Рогалик-менеджер в пиксель-арте. Завод растёт от маленького цеха досок до абсурдных производств вроде кетчупа. Игрок расставляет станки и работников, собирает карточки, и они комбинируются по соседству.
