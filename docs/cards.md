# Карточки

## Типы

| Тип | Примеры |
|---|---|
| Сотрудники | +1 сотрудник, +2 сотрудника, Бригадир, Стажёр |
| Сила / скорость | +сила сотрудника, +10% скорости |
| Экипировка (в шкафчик) | каска, перчатки, кофе, бензопила, реактивный ранец |
| Станки | пилорама, пресс, печь, конвейер, робот-рука |
| Особые | «каждый 10-й товар двойной», «раз в минуту премия» |

**Редкость:** обычная (серая), редкая (синяя), эпическая (фиолетовая), легендарная.

## Как карточки комбинируются

1. **Общая формула:** `доход = сотрудники × сила × скорость × станки × множители`. Любая карточка усиливает остальные.
2. **Соседство:** карты взаимодействуют только у соседних станков и работников (см. [первую локацию](location-1.md)).
3. **Связки по тегам:**
   - две карты одного тега дают бонус всему тегу. Пример: «+1 сотрудник» и «+2 сотрудника» дают всем сотрудникам +0,5% силы;
   - карты разных тегов дают перекрёстный бонус;
   - чем больше карт одного тега, тем сильнее связка (на 2, 4, 6 картах).
4. **Именные легендарные комбо.** Пример: «Кофе» + «Конвейер» + «Стажёр» = «Ночная смена».

## Карточки, меняющие правило соседства

| Карточка | Эффект |
|---|---|
| Конвейер | Станок связан со всем рядом |
| Вентиляция | Станок связан со всем столбцом |
| Длинные руки | Станок достаёт до диагоналей |
| Одиночка | Сильнее, если соседей нет |

## Способы получения

- Новый уровень завода: выбор 1 из 3.
- Посылки, съезжающие с конвейера (тапнуть, чтобы открыть).
- Заказы клиентов.
- Магазин карт.
- Стартовая карта при открытии цеха.
- Слияние: 3 одинаковые карты дают 1 улучшенную.
- Ежедневная награда.

## Иконки (билд 2)

У каждой карточки есть пиксельная иконка 16×16 в общей палитре. Иконки рисуются в коде и показываются на карточке, в колоде и в списке экипировки.

Список: верстак, пилорама, сушилка, шлифовка, глиномешалка, пресс, печь, конвейер, портрет Бродяги, гантели, секундомер, радио, стопка кирпичей, кружка, каска, перчатки, респиратор, подкова, бензопила, полотно, лак, глазурь, маслёнка.
