# Сотрудники

## Правила

- У каждого работника есть **шкафчик** в раздевалке. В нём лежат его карточки экипировки.
- Работник **прикрепляется к станку**. Карты из его шкафчика действуют на этот станок и через него на соседей.
- **Соседи по шкафчику дружат** и дают друг другу бонус (на макете это сердечко между шкафчиками).
- Шкафчики открываются с прогрессией. Закрытые показаны с замком.

## Ворона

- **Роль:** оператор пилорамы.
- **Характеристики:** сила 6, скорость 8, удача 5.
- **В шкафчике:** защитные очки, перчатки без пальцев.
- **Перк «Меткий распил»:** каждая 7-я доска выходит двойной.
- **Образ:** по мотивам референса, но перерисован и изменён:
  - тёмные волосы-«волчий хвост» с бирюзовой прядью;
  - защитные очки на лбу;
  - пирсинг;
  - рабочая форма: оливковый тактический жилет, футболка, карго, ботинки.

## Мистер Жопосранчик

- **Роль:** помощник у верстака.
- **Характеристики:** сила 4, скорость 3, удача 9.
- **В шкафчике:** цилиндр, кружка кофе.
- **Перк «Ооо-ви-и!»:** +5% силы соседу по шкафчику. Без кофе работает вполсилы.
- **Образ:** цилиндр, красные уставшие глаза, щетина, халат, кружка кофе.
- **Права:** персонаж из чужой вселенной. Для публикации в сторе его нужно заменить на узнаваемую пародию.

## Идеи на будущее

Новые сотрудники приходят через карточки «+1 сотрудник». Можно добавить и других гостей из разных вселенных.
