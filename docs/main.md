## Решено

- **Платформа:** мобильная игра.
- **Графика:** милый пиксель-арт. Спрайты около 32 px, мягкая палитра, цветной контур. Детально, но без перегруза.
- **Сеттинг:** игра начинается с маленького завода, который растёт. Деревни нет.
- **Главная механика:** карточки улучшений (сотрудники, экипировка, станки и другое), которые комбинируются между собой.
- **Расстановка:** станки стоят на сетке, у каждого работника свой шкафчик. Карты взаимодействуют только у соседей.
- **Ветки завода:** каждая пристройка выпускает новый продукт, и продукты становятся всё абсурднее.
- **Прогрессия:** бесконечная.

## Ветки завода (цеха)

доски → кирпичи → гвозди → стекло → мебель → носки → пицца → **кетчуп** → резиновые уточки → тостеры-роботы → …

Каждый цех — отдельная локация со своей сеткой, станками и карточками. Вариант для глубины: поздние цеха используют продукцию ранних (кетчупу нужны бутылки из стеклянного цеха).

## Бесконечная прогрессия

Числа растут без потолка: K, M, B, T и дальше. Сетка цеха расширяется: 3×3 → 4×4 → 5×5. Время от времени завод можно перезапустить ради постоянного бонуса. Каждый новый забег начинается с другим набором карточек.

## Сотрудники и цеха

Каждый сотрудник существует в одном экземпляре и работает только в одном месте на весь завод. Раздевалка общая для всех цехов. Если перевести сотрудника в другой цех, он уходит со старого места.
